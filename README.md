# VidCam · Bản phát hành

Nơi tải VidCam cho macOS (Apple Silicon, macOS 15 trở lên).

- **Tải về:** xem mục [Releases](https://github.com/sonlovinbot-team/vidcam-releases/releases/latest).
- **Lần đầu mở trên máy khác:** bản nội bộ ký bằng chứng chỉ riêng, macOS sẽ chặn. Chuột phải vào VidCam › Mở › Mở.
- **`news.json`:** app VidCam đọc file này (qua GitHub Pages) để biết có bản mới. App chỉ gửi một yêu cầu GET thường, không gửi ID hay dữ liệu người dùng.

Repo này không chứa mã nguồn.
